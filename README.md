   - Bouton d'impression optimisé pour exporter l'emploi du temps propre au format papier ou PDF.

## 🚀 Comment déployer sur Cloudflare Pages (Gratuit en 2 minutes)

### Méthode 1 : Dépôt direct (Glisser-Déposer)
1. Rendez-vous sur votre compte [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. Dans le menu de gauche, cliquez sur **Compute (Workers & Pages)** > **Pages**.
3. Cliquez sur **Upload assets** (Téléverser des fichiers).
4. Donnez un nom au projet (ex: `master-ens-meknes`).
5. Glissez-déposez l'ensemble du dossier `ens-meknes-master` (contenant `index.html`, `js/`, `css/`, etc.).
6. Cliquez sur **Deploy site**.
7. 🎉 Votre site est en ligne instantanément avec une adresse gratuite du type : `https://master-ens-meknes.pages.dev` avec certificat SSL gratuit !
